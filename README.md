# Yomira Sample Content

This public repository contains only the original Neon Meridian demo manifest, normalized JSON responses, and sample images used to exercise Yomira's native JSON REST source engine. It contains no Yomira application source code, credentials, or user data.

Add this manifest URL in Yomira under **Settings → Sources → Source Repositories**:

`https://raw.githubusercontent.com/Nyzerion/Yomira-Sample-Content/main/ReferenceSource/repository.json`

The fixture is intentionally small and is for testing the reader and source engine, not a general manga catalog.
